首次使用按应用 Settings 中的检查清单完成:

1. 确认 [系统要求](https://kxen.ai/getting-started/requirements) 和安全默认值。
2. 注册 [第一个 Workspace](https://kxen.ai/getting-started/first-workspace)。
3. 连接至少一个 Provider，并确认账号状态。
4. 检查 thinking、planning、execution、review 和 research 的角色路由都有可用落点。
5. 完成 [第一个 Session](https://kxen.ai/getting-started/first-session)。

Browser automation、Remote MCP 和自动知识沉淀保持默认关闭，只有理解数据边界后再逐项开启。当前发行资格单独见 [可用性](https://kxen.ai/overview/availability)。首次使用的目标是确认 Workspace、Provider、模型、路由和基础工具形成完整闭环。
