后台任务用于不能阻塞当前 Agent 回合的本地进程，例如开发服务器、watcher 和长时间构建。

## 启动

Agent 可以通过 task 工具启动进程。任务获得独立 task ID，并记录命令、工作目录、输出、运行时间和进程状态。

开发服务器可以声明 readiness 条件。kxen 等待输出模式或端口可达后返回可用状态，避免用固定 sleep 猜测启动时间。

## 管理

后台任务支持:

- 查看任务列表。
- 读取累计输出。
- 停止任务。
- 使用相同命令重启。
- 查看端口、运行时间和输出尾部。

任务完成时会产生通知，Agent 不需要反复轮询。

## 产品入口

当前 Session 的后台任务显示在右侧 Dock。状态栏显示当前 Session 中仍在运行的任务数，未选中 Session 时为 0；Workspaces 看板当前只汇总运行中 Session、Queue、Goal、Schedule、Worktree 和 Git 状态，不单列后台进程。

## 生命周期边界

后台任务属于本次应用运行环境，不是系统级守护进程。停止应用、系统终止进程或任务自身退出后，不能把旧状态当成仍在运行。

启动命令仍经过 Shell Safety 和 Approval。后台执行不能绕开高风险命令检查。
