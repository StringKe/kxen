Command 是由用户显式触发的命令入口。它适合高频动作和需要明确参数提示的任务模板。

## 产品入口

在 Composer 行首输入 `/` 查看 Command。`Cmd+K` 命令面板也可以搜索并插入 Command。

Slash Command 只在消息行首触发。正文中间的 `/` 不会展开成 Command，避免普通路径或文本被误识别。

## 内置 Command

当前内置 Command 包括:

- `/write-goal`
- `/ultracode`
- `/ultraplan`
- `/ultrareview`
- `/doctor`
- `/compact`

这些内置项不从知识目录读取模板正文。`/doctor` 和 `/compact` 由后端精确识别并执行；`/write-goal` 与三个 `/ultra*` 模式进入普通 Agent run，再按内置 system prompt playbook 编排，因此仍需要可用模型。

`/compact` 立即尝试把当前 Session 的较旧模型上下文压缩为持久摘要，不删除原始 Session JSONL。新建 Session、切换模型和中断运行分别使用「新会话」动作、Model Picker 或 Command Palette 和 Composer Stop 按钮，它们不是 Slash Command。

## 自定义 Command

项目 Command 放在 `file:///path/to/workspace/.agents/commands/`，个人 Command 放在 `file:///Users/you/.agents/commands/`。

自定义 Command 支持:

- `description`
- `argument-hint`
- `needs`
- `$ARGUMENTS` 和位置参数

发送时，kxen 展开模板和依赖知识，再交给当前 Session 处理。

## 信任边界

未信任 Workspace 的项目 Command 可以出现在索引中，但不会展开项目提供的正文。Command 不能通过模板获得当前角色没有的工具，也不能绕开 Safety。

## 与 Skills 的区别

Command 始终由用户通过 `/` 显式触发。Skill 既可以由用户触发，也可以在允许时由模型按需加载。
