kxen 当前是开发预览，不是公开发行版本。

## 当前可用范围

- 目标系统是 macOS 14 及以上版本。
- 目标架构是 Apple Silicon。
- 开发者可以从源码构建和运行。

## 当前不可用范围

- 官网没有公开下载按钮。
- GitHub Releases 尚未发布面向公众的签名安装包。
- 稳定自动更新通道尚未开放。
- Windows、Linux 和 Intel Mac 不在当前支持范围内。

## 不应推断的承诺

仓库中出现的平台代码、构建配置或实验实现，不代表对应平台已经可用。Provider 出现在注册表中，也不代表用户账号已经获得对应模型权限。

准备从源码运行前，继续查看 [系统要求](https://kxen.ai/getting-started/requirements)。
